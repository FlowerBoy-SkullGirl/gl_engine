Shaders

The programs that run on the GPU to draw images on the screen. In the GPU pipeline, the local coordinates given by a mesh's vertex buffers are first transformed into 'world space' coordinates relative to other objects. The world coordinates are then transformed into 'screen space' coordinates, determining what section of the 'world space' is viewable when the image is rendered. These transformations all take place in the vertex shader, and the output is passed to the fragment shader. The fragment shader determines how each resultant pixel is drawn, and also controls the color of the pixel. Information is passed from the CPU program to the shader programs running on the GPU through 'uniform' values.

vertex.glsl

Input layout
  • vec2 local_coords: location 0
  • vec2 tex_coords: location 1
Note that the location is an offset in the buffer, so the shader knows to find local_coords by skipping every other vec2, starting at index 0.

Uniforms
  • uniform float rotationRad - The rotation of an object in radians, relative to world space.
  • uniform vec2 scalars - The x and y scale of an object.
  • uniform vec2 translation - The x and y displacement of an object relative to world space origin.
  • uniform vec2 screen_scalar - The x and y scalars to transform world space into screen space.
  • uniform vec2 cameraPos - The x and y world coordinates of the 'camera' object that determines the origin of screen space.

Output layout
  • vec2 frag_tex_coords - the coordinates passed to the fragment shader after all vertex transformations have taken place.

fragment.glsl

Input layout
  • vec2 frage_tex_coords - Passed from the results of the vertex shader.

Uniforms
  • vec4 color - The rgba color of a given object to be drawn
  • sampler2D texture1 - The texture image data assigned to a given object
  • bool useTexture - Whether an object should be drawn with a texture (otherwise, the shader defaults to the rgba color)
