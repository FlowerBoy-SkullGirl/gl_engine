gl_engine is a 2D game engine written in C and C++ that allows for basic shapes to be drawn from meshes, have textures applied to them, and accepts programmer-defined actions for different keybindings.

File system structure

Project Root /

  • Makefile - instructions for GNU Make to build the project.

Binaries /bin

  • Stores the executable files built with the Makefile in the project root directory
  • square - the executable built from src/main.cpp that incorporates every element of the project.

Documentation /docs

  • Stores the documentation for the project, including this file.
  • index.html - the entry point for the documentation.

Mesh files /meshes

  • Example meshes provided for use in the program. A mesh holds coordinate information for drawing shapes.

Object files /objects

  • A directory for a planned feature that would enable objects to be built from specifications listed in a file.

Shaders /shader

  • The OpenGL shaders written in glsl that are compiled at runtime.
  • vertex.glsl - Describes and performs transformations of object vertices from local coordinates to world coordinates and world coordinates to screen coordinates.
  • fragment.glsl - A very simple fragment shader that applies the requested textures for an object and the requested colors for a given object.

Source files /src

  • The location of all .c and .cpp files used to build the program.

Header files /src/headers

  • Accompanying header files for the files found in /src.

Textures /textures

  • Image files that are used to apply textures to objects. These are png files that are parsed by stbi and used by the main function through the project's textures library.

Below is a high level overview of how system libraries interact with one another. A game object is the most abstracted class, which has many hitboxes, one mesh that may be attached to many game objects, an rgba color struct, a velocity struct, and a texture integer. Each mesh has one shape and a fixed number of buffer_t objects that should be initialized with the mesh. The buffer, shaders, and textures library all wrap the OpenGL API to abstract some of its functionality.
